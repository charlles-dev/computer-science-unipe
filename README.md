## 📖 Sobre o Repositório

Este repositório funciona como meu **portfólio acadêmico vivo** durante a graduação em **Ciência da Computação** pela **UNIPÊ**.

O objetivo é:
- 🗂️ Manter histórico versionado de códigos, algoritmos e projetos práticos;
- 🧠 Documentar meu processo de aprendizado contínuo, lógica e resolução de problemas;
- 🚀 Construir uma base sólida de portfólio prático alinhada às exigências do mercado de tecnologia.

---

## 🗂️ Estrutura de Pastas

A organização é segmentada por **períodos**, **disciplinas** e **tipos de atividade** para garantir escalabilidade e fácil navegação:

```text
computer-science-unipe/
├── assets/                                      # Banners, gifs, diagramas e ilustrações
│   └── banner.gif                               # Banner principal do topo do README
│
├── periodo-1/                                   # 1º Semestre (Atual)
│   ├── algoritmos-pensamento-computacional/     # Algoritmos e Pensamento Computacional (90h)
│   │   ├── exercicios/                          # Listas e exercícios práticos semanais
│   │   ├── projetos/                            # Trabalhos e avaliações práticas
│   │   ├── notas/                               # Resumos e anotações de aula
│   │   └── README.md                            # Visão geral da disciplina
│   ├── desenvolvimento-front-end-web/           # Desenvolvimento Front-End para Web (90h)
│   ├── design-profissional/                     # Design Profissional (90h)
│   └── modelagem-banco-dados/                   # Modelagem de Banco de Dados (90h)
│
├── periodo-2/                                   # 2º Semestre
├── periodo-3/                                   # 3º Semestre
│   └── ...
│
├── projetos-destaque/                           # Projetos integradores, interdisciplinares ou hackathons
└── certificacoes-cursos/                        # Cursos extracurriculares e certificados complementares
```

> [!TIP]
> Cada disciplina conta com sua própria pasta estruturada e um `README.md` contendo tópicos estudados, desafios e instruções de execução.

## 🚀 Como Navegar e Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/charlles-dev/computer-science-unipe.git
   cd computer-science-unipe
   ```

2. **Navegue até a disciplina ou projeto desejado:**
   ```bash
   cd periodo-1/algoritmos-pensamento-computacional
   ```

3. **Consulte o README local** da pasta para orientações de compilação ou execução dos projetos.
