# Desenvolvimento Front-End - Experiência Prática 2 (UNIPÊ)

Evolução da plataforma institucional da **ONG Esperança Viva**, implementando:
- **Design System Modular:** Variáveis CSS `:root` com paleta completa, escala tipográfica e espaçamento em grid de 8px.
- **Layout Responsivo:** CSS Grid de 12 colunas adaptativo e Flexbox para componentes internos.
- **Micro-interações & Feedback:** Badges semânticos, caixas de alerta, modal acessível e notificações toast.
- **Navegação Adaptativa:** Menu desktop com dropdown e condensação mobile em hambúrguer.

## 📂 Arquivos do Projeto
- `index.html`: Página inicial institucional.
- `projetos.html`: Catálogo de ações e módulo de doação PIX.
- `cadastro.html`: Formulário acessível de voluntários.
- `componentes.html`: Vitrine dos componentes de feedback (Badges, Alertas, Modal, Toast).
- `assets/css/style.css`: Folha de estilos completa com tokens de design e estados interativos.
- `assets/img/`: Imagens e ícones vetoriais.
