# Desenvolvimento Front-End - Experiência Prática 1 (UNIPÊ)

Projeto institucional desenvolvido para a **ONG Esperança Viva**, alinhando estruturação semântica em HTML5, conformidade estrita com o W3C, acessibilidade web (WCAG) e design visual moderno.

## 📂 Localização e Estrutura de Arquivos
- **Caminho no repositório:** `Desenvolvimento Front-End Web/Desenvolvimento Front-End Experiência Prática 1/`
- **Arquivos:**
  - `index.html`: Apresentação institucional, hero visual e canais de contato.
  - `projetos.html`: Cards de projetos, voluntariado e módulo de doações via PIX.
  - `cadastro.html`: Formulário com fieldsets temáticos e validações estritas (CPF, CEP, Telefone).
  - `assets/css/style.css`: Folha de estilos moderna e responsiva.
  - `assets/img/`: Imagens e ícones vetoriais em formato SVG otimizado.
