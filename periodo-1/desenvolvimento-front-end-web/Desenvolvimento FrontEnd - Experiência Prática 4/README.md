# Desenvolvimento Front-End - Experiência Prática 4 (UNIPÊ)

Etapa final de consolidação, qualidade e publicação da plataforma institucional da **ONG Esperança Viva**:
- **GitFlow & Versionamento:** Governança com ramificações (`main`, `develop`, `feature/*`), Conventional Commits e versionamento semântico (`SemVer`).
- **Acessibilidade Completa (WCAG 2.1 AA/AAA):** Landmarks semânticos, atributos WAI-ARIA, suporte total a navegação por teclado (focus trap) e perfis cromáticos de alto contraste / dark mode.
- **Preparação para Produção & Bundler:** Minificação de CSS, JS e HTML via Vite / esbuild, otimização de imagens vetoriais SVG (redução superior a 90% de payload).
- **Deploy & CI/CD:** Publicação automatizada em ambiente de produção acessível globalmente via GitHub Pages.
